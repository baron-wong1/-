# 发票整理助手使用说明

## Windows 使用

下载 Windows 构建任务产出的 `InvoiceAssistant-Windows-x64`，解开外层 artifact 包和里面的应用 ZIP。将整个目录放到本机可写位置，双击 `发票整理助手.exe`。不要只复制 EXE：`resources` 包含识别核心、OCR 模型和 Word 转换组件。

首版目标是 Windows 10/11 x64。本应用尚未代码签名；系统可能显示未知发布者提示。无需安装 Python、Node、Office 或在线服务。第一次启动会检查离线组件。

## 整理流程

1. 点击「选择文件」「选择文件夹」，或拖入文件/文件夹。支持 PDF、DOCX、DOC、JPG/JPEG、PNG；文件夹递归读取，工具、缓存和输出目录自动排除。
2. 填写报销人和报销月份。月份与票面的开票日期独立；首次启动为空，不会预填示例姓名或数据。
3. 查看「待核对」。点每行铅笔按钮查看原件并修改类型、分类、票号、日期、金额和页范围。扫描/OCR 数字需要人工核对；不清楚的金额不会按零处理。可新增自定义分类。
4. 付款截图改为「付款附件」，不计入发票张数、金额和 Excel 明细。仍按分类放入打印 PDF，最多半页。
5. 多张发票出现在同一页时，在预览上拖动选出第一张完整票据，点「重新识别选区」，核对后点「从本文件拆分另一张」。该操作保存当前票据并新建一条待核对记录。继续选择第二张的不重叠区域；也可用起止页拆分多页文档。连续多页的同一张票只保留一条，设置完整页范围，移除多余页记录。
6. 同号且日期、金额和类别相同的完整票据自动排除重复项。关键字段不一致会标记冲突；修订或移除错误记录。确为需要同时保留的同号票据时，逐项查看原件并勾选确认。移除保留项后，剩余重复项会自动恢复。
7. 待核对、错误和冲突项全部处理完成后，点击「生成打印件和统计表」并选择输出位置。失败记录可移除，原文件不会删除。

## 输出文件

每次创建一个新的 `发票整理_时间戳` 文件夹，里面包含各非空分类 PDF、全部合并 PDF、六列 Excel 明细及分类汇总。分类默认顺序：住宿、车票、市交、退票费、其他，然后是自定义分类。各类别按开票日期、可用行程时间、票号和稳定记录 ID 排序。

PDF 为 A4 纵向：每页最多两张，长票单页，附件最多半页。完整保留页面内容，不自动裁掉票号、印章或二维码；打印前请检查自选裁剪是否完整。合并版有连续页码和分类书签，无额外左上角标记。

Excel 列为：报销日期、报销人、发票内容、发票金额、开票日期、发票号码。发票号码按文本存储，保留开头的 0 和长票号；明细、总额和分类汇总不附加来源说明。

## 取消、恢复与原件

导入时可取消任务；已经识别的记录保留。导出取消时清理未完成的临时输出目录。应用自动在本机保存整理会话，重启可继续；请勿移动或修改原文件，否则预览和导出会提示重新导入。

「清空列表」只删除会话记录和临时转换副本，保留原件。程序不上传票据，不使用云端 OCR，也不在运行时下载模型。报销信息、文件路径和修订值保存在本机用户数据目录；处理私人材料请使用受保护的系统账户。

## 已知边界

识别规则不能保证所有供应商版式都自动正确；OCR 结果必须对照原件核对。加密 PDF、损坏文件、无法转换的 Word 会显示错误，其他文件继续识别。大型扫描件和 Word 转换耗时较长，每份 Word 转换最多 120 秒。

Windows 构建成功只说明候选包构建和自动烟测通过；在实际 Windows 10/11、断网、无预装开发环境和打印机上的完整验收另行记录。macOS 需在对应 Mac 上构建，Windows 包不能在 Mac 直接运行。
