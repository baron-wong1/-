# 发票整理助手轻量版使用说明

适用 Windows 10/11 x64。完整解压发行 ZIP，双击「发票整理助手.exe」，不要单独移动 EXE；旁边的 DLL 是整理 PDF 所需的小型库。

## 整理

1. 输入报销月份（例如 `2026-10`）和报销人。两者首次为空，开票日期独立于报销月份。
2. 选择文件、选择文件夹或拖入票据。支持 PDF、JPG/JPEG、PNG、DOC/DOCX；文件夹递归导入会跳过工具和已有输出目录。相同内容的文件不会重复加入。
3. 双击需要核对的行，查看原件，修改类别、票号、开票日期及金额。自定义类别可直接输入。缺失金额不会按零计入。
4. 查看提示并勾选「已查看原件并核对字段与票据范围」，确认保存。无法读取的项目显示失败，可移除后继续整理其他票据。
5. 所有项目就绪或重复后，点「生成打印件和统计表」，选择输出位置。工具新建一个结果文件夹，不覆盖原件。

## 自动识别与 Word

文本 PDF 自动提取原有文字。扫描 PDF、图片使用 Windows 已安装的中文文字识别，应用不会下载模型。缺少中文识别组件时会提示人工填写；如需启用系统能力，可在 Windows 语言设置安装中文基本输入。系统识别仍需人工核对。

Word 转换需要本机已安装的 Microsoft Word。缺少或转换失败时，该项会显示原因；可在 Office 中另存为 PDF 后再导入。转换只读取临时副本，禁用宏，超过 120 秒中止。不随包提供 Office。

使用系统 .NET Framework 4.8；较早 Windows 10 缺少时需先安装微软的系统组件。工具没有账号、联网识别或订阅功能。

## 多票、多页与重复

同一页包含多张发票时，在核对窗口右侧拖动框选一张票据，填写并确认字段。主界面选择该行，点「复制拆分」为另一张票据建立一行，再框选另一部分。各裁剪范围不能重叠。框选失误可「恢复完整页」后重新操作。

一个 PDF 多页时，每页建立独立待核对项。若多页属于同一张发票，在一行调整页范围，并移除覆盖同一范围的其他行；核对窗口显示起始页。日期、金额和票号每张发票仅统计一次。

同号且金额、日期、类别一致的记录自动标为重复，导出排除。字段不同会标为冲突，请修订或移除；确需保留时，每个冲突项均需勾选「已核对，同号字段冲突仍保留此项」。付款凭证选择「付款附件」，作为打印附件，不计入发票张数及金额。

## 输出与保存

每个非空类别生成一份 PDF，另有带类别书签及连续页码的合并 PDF。A4 纵向，每页最多两張，长票单页，附件最多半页。保留原件内容，不自动裁掉边缘。原 PDF 文字与图形保持原有质量。

Excel 包含报销日期、报销人、发票内容、发票金额、开票日期、发票号码六列，以及总额、分类张数和金额汇总。票号完整保留，附件及重复票不计入金额。

记录和预览副本保存在本机 `%LOCALAPPDATA%\InvoiceAssistantLight`，下次启动自动恢复。不要把该目录或真实票据提交到公共仓库。清空按钮清除列表及保存的会话，原件不会删除；预览缓存可能仍在本机，需要清理时先关闭工具，再删除上述目录。

导出前会检查原文件是否仍在原位置且未被修改。若发生变化，请移除该项后重新导入。任务可取消；已导入的项目保留，取消的导出不会保留半成品结果。

本包是未签名候选版。实际断网启动、中文 OCR、本机 Office 转换和打印效果需在目标电脑核实。
