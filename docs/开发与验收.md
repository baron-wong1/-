# 轻量版开发与验收

当前入口为 `lightweight/InvoiceAssistant.csproj`，Windows 10/11 x64，C# WinForms、系统 .NET Framework 4.8。构建用 .NET SDK 8.x；全部 NuGet 版本及传递依赖锁定在 `packages.lock.json`。

## 构建

```sh
dotnet restore lightweight/InvoiceAssistant.csproj --locked-mode
dotnet build lightweight/InvoiceAssistant.csproj --no-restore -c Release -o build/lightweight
python scripts/package-lightweight.py
```

打包脚本只复制 EXE、DLL、配置、说明及许可；不复制 SDK、Python、系统 Windows 元数据或 OCR 模型。产物在 `release/`，包含发行 ZIP、SHA256 和实际文件体积清单；超过 10 MB 会失败。

## 自动验证

Windows Actions 生成合成 PDF/PNG/JPEG/DOCX，然后启动打包目录中的真实应用，执行 `--self-test <QA目录>`。验证空会话、票号及日期、定点金额、重复/冲突、多票拆分、范围重叠、真实 PDF 导入、坏文件隔离、图片导入、系统 PDF 预览、旋转、多页、系统能力缺失提示、桌面导出、A4 排版、附件计数、书签页码、XLSX 字符串及公式安全、取消、会话序列化和原件哈希。

系统 OCR 使用 runner 已安装的语言进行真实 API 检查；中文语言未安装时验证明确的人工补录提示，不声称验证了中文识别。Microsoft Word 未安装时验证单项错误提示，不声称验证了 Office 转换。`verify-lightweight-output.py` 另外用 PyMuPDF/openpyxl 重读输出，确认 PDF 文字、页码及书签、六列、完整票号、日期和 133.55 的精确合计；这些 Python 库仅用于构建验证，不进入产品。

成功产物附自检报告、实际桌面截图、预览及打印页图像。当前 PR 为草稿，未自动合并或发布正式版本。

## 实机验收

仍需在干净 Windows 10 与 11 上解压双击、断网整理真实样本、查看 Excel 中文与完整票号、实际 A4 打印。分别记录系统 .NET 4.8、中文识别语言能力、Office 是否安装，再验证系统 OCR 和 DOC/DOCX 转换。用户 Mac 中原始界面截图及私人票据未同步至此环境，不能宣称已经逐像素对照或真实票据验收。macOS 需要独立原生实现及构建。
