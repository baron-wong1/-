# 轻量版体积与功能取舍

0.1.0 完整包约 781 MB，0.1.1 裁剪后仍约 497 MB。主要来自随包 Office（约 247 MB）、Electron（约 141 MB）及 Python/OCR（约 105 MB）。用户明确要求更小的工具后，0.2.0 改用 Windows 系统运行环境和原生界面。

当前发行包只含 C# 应用、PDFsharp/PdfPig 小型库及其托管依赖、使用说明与许可。系统 .NET Framework、PDF 预览、OCR、已安装 Office 均不复制进包，也不会在运行后下载。ZIP 构建预算上限 10 MB，压缩及解压后实际字节数和每个文件大小见 `footprint.json`。

轻量化的实际取舍：文本 PDF 自动提取；图片/扫描件识别需系统已有中文识别能力，缺少时人工补录；Word 转换需已安装的 Microsoft Word，缺少时先转 PDF。PDF 和 Excel 导出不需要 Office，保留分类、金额精度、票号、重复核对、范围裁剪及附件规则。

旧版依赖及开发目录留在 Git 历史/源码中作参考，不参与当前打包。不得通过小型启动器在运行时下载旧版大运行环境来虚报发行体积。
