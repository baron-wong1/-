# 包体积优化

原始 0.1.0 Windows 构建产物为 781,022,522 字节（含 Windows ZIP 和校验文件）。该包采用完整 LibreOffice 和 OpenCV、Electron 默认语言包，并重复携带已编译进前端的 npm 模块。

0.1.1 保留 React/Electron、离线 OCR 和无需安装 Office 的 DOC/DOCX 支持，进行以下裁剪：

- Python 打包时优先使用固定 SHA-256 的 OpenCV headless wheel；开发环境依赖不被替换。移除仅用于 Windows 视频读写的 FFmpeg 插件，以及本工具未使用的可选 fontTools/lxml 模块。
- Electron 保留中文和英文语言包；前端依赖已经编译进 `dist`，主进程只调用 Node/Electron 内置模块，发行目录不重复放入原始 npm 模块。
- LibreOffice 移除交互图库、新建模板、AutoText、向导、脚本示例、Calc 求解/Wiki 发布扩展、脚本 Python 标准库、替代图标主题和其他 UI 翻译。保留默认 Colibre 图标、中文/英文翻译、所有渲染及导入 DLL、注册配置、词典、字体和许可文件。
- 使用普通 ZIP 压缩，Windows 自带解压功能可用。没有删除 OCR 模型，也不改变处理算法或降低图片分辨率。

Windows CI 先用完整 Office 转换合成 DOCX 和 DOC，保留中文、英文、金额、两页分页、表格和嵌入图片的渲染与文本指纹；裁剪后用新缓存重新转换，逐页像素和文本指纹必须完全一致。随后验证独立 OCR 核心、完整导出以及最终打包后的桌面流程。

构建产物附带 `package-footprint.json` 和 `word-trim.json`，分别记录各组件压缩前/后的字节数以及移除项。完整包和瘦身包的对比使用实际构建数据，不以源代码大小估算。裁剪资源列表固定在脚本内；修改列表必须重新通过 Word 转换对照和最终包烟测。

这仍是带浏览器、文档排版引擎和识别引擎的完整离线发行包。干净 Windows 10/11 断网实机及打印验收仍单独记录。
