# 轻量版实施记录

用户明确要求小工具不携带大运行环境，0.2.0 用系统能力替代完整离线组件。以既定 Windows 10/11 x64 基线推进；系统与识别取舍仍可按用户反馈调整。

1. C# WinForms 单页界面，选择文件/文件夹、拖入、核对、范围拆分和导出。
2. PDFpig 提取原 PDF 文字，PDFsharp 保留原件文字图形并排版。Excel 用系统 ZIP/XML API 直接生成。
3. Windows PDF 预览和已安装中文 OCR；未安装时人工核对。Word 使用本机 Microsoft Word，独立子进程限制转换时长并禁用宏，未安装时先转 PDF。
4. 保留十进制金额、字符串票号、附件规则、去重/冲突、重叠范围检查、原件哈希、任务取消和本机会话保存。
5. Windows 构建启动真实打包应用，用合成材料验证桌面流程，再独立重读 PDF/XLSX。ZIP 限制 10 MB，输出真实体积清单和对应源码提交。

不随包包含 Electron、Node、Python、LibreOffice、OCR 模型或 SDK；不在启动后下载这些运行环境。构建机上使用的开发及验证组件不进入产品。

实际中文系统 OCR、已安装 Office 的 DOC/DOCX 转换、干净 Windows 10/11 断网启动和打印仍需对应目标机验收。已选 Mac 私人截图不可在当前云端读取，界面未做逐像素对照。macOS 原生版尚未制作。
