# 发票整理助手实施计划

依据：2026-10-03 设计说明；用户已要求完成制作，按该授权直接实施。

1. Python 核心：逐文件/逐页导入、内容哈希、文本优先和离线 OCR、隔离 Word 转换、解析与人工核对、重复/冲突检查。
2. React + Electron：空白初始状态、选择和拖放、进度/取消、明细编辑、原件预览、页范围及裁剪、多票拆分、自定义分类、移除和恢复会话。
3. 统一导出：Decimal 金额、稳定日期顺序、A4 两票/长票单页/附件半页、分类和合并版、连续页码和书签、六列 Excel 和分类汇总、原件不改写、原子提交输出目录。
4. 发布：PyInstaller 独立核心，electron-builder Windows ZIP；OCR 模型和 LibreOffice 随包，启动检查；GitHub Actions 在 Windows 上构建和烟测。
5. 验证：合成 PDF/图片/扫描/Word、多票/多页、重复冲突、错误隔离、裁剪及金额一致性、界面操作、打包核心协议。

界面遵循既定的简洁单页布局；原选定截图在本机私人目录，未进入公开仓库，因此本次以通用设计文字为可访问基准。不得上传真实发票、个人截图、报销数据。

交付边界：本环境可验证处理逻辑、界面和 Linux 核心构建；Windows CI 产物和干净 Windows 10/11 断网实机验收分别记录，不把构建结果等同于实机验收。
