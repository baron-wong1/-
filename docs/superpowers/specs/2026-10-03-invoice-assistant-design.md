# 发票整理助手设计说明

日期：2026-10-03。状态：界面方向已确认，完整设计待审阅，产品尚未实现。

## 目标

把发票拖入或手动选择后，自动按票面类型整理为分类打印 PDF、合并 PDF 和一份 Excel 统计表。Windows 用户解压完整发行包后双击启动，无需配置开发环境。

## 主界面

采用简洁单页：顶栏提供选择文件、选择文件夹、格式提示、报销月份和报销人；中间是拖放区；下面是文件、分类、开票日期和金额明细；底部为生成打印件和统计表按钮。

报销人可直接输入，报销月份可手动修改或选择年月。分类可修改，识别字段通过行内修改入口核对。示例数据不作为运行数据；首次使用报销信息为空。

## 输入与识别

明确支持 PDF、DOCX、DOC、JPG/JPEG、PNG。文本 PDF 优先提取原文本；图片、扫描 PDF 使用本地 OCR；Word 转换为 PDF 后使用统一处理流程，保留文字、表格及嵌入图片信息。

一个文件可含多张票据或多页发票。无法可靠拆分时标记待确认，由用户确认范围，不复制第一张发票金额到整个文档。坏文件或转换失败不得静默丢失，也不得阻止其他文件识别。

文件夹递归导入时排除工具自身、临时及输出目录。重复导入通过文件身份检查；同名不同内容保留。

## 分类与金额

默认类别：住宿、车票、市交、退票费、其他，可自定义类别。文件夹名称为建议，票面证据和用户修订优先。

采用票面价税合计、客票票价或退票费，使用十进制定点数。发票号码始终保存为字符串。报销月份与开票日期独立。

同号且关键字段一致的票据保留一条；同号但金额、日期等冲突需确认。缺失字段不替换为零。付款凭证作为附件，不纳入发票张数和金额。

## 输出

- 每类按开票日期排序，同日再按可用行程日期时间、发票号码和稳定记录 ID 排序。
- A4 纵向，每页最多两张；长票单页；附件截图半页或更小。
- 保留票号、金额、二维码、印章与备注，去除周围空白时不能裁掉内容。
- 不添加左上角说明；合并版采用连续页码和类别书签。
- 输出各非空类别 PDF，以及按类别合并的总 PDF。
- Excel 六列：报销日期、报销人、发票内容、发票金额、开票日期、发票号码。保留总额和分类张数、金额汇总；不附加来源说明。

## 实现方向

React 单页界面，Electron 桌面窗口，独立 Python 处理核心。处理边界为文件导入、Word 转换、OCR、字段解析、分类去重、PDF 排版和 Excel 生成。

OCR 模型、Word 转换组件和运行依赖随包提供，发行版无需依赖 Codex 运行时。组件许可说明随包保留。文档宏不执行，文档内容不作为系统指令。

首版 Windows 10/11 x64 为设计基线，其他系统版本的支持需独立核实。Mac 和 Windows 分平台打包。Windows 候选包在 Windows 环境构建，构建成功不替代断网、无预装开发环境下的实际验收。

## 验收

覆盖普通 PDF、扫描 PDF、图片、DOCX、DOC、多票及多页材料；核对票号、日期、含税金额、分类、去重及人工修订。保存原文件，输出张数与金额跨 PDF/Excel 一致。

界面验证选择文件、选文件夹、拖放、编辑报销信息、修订字段、移除错误项、取消任务和导出。对照已选界面验证版式。

逐页检查打印件，重新读取 Excel 并在表格软件中检查完整票号与中文显示。Windows 发行包必须在干净 Windows 环境解压双击、断网走完整流程并检查打印。
