# 发票整理助手

面向 Windows 的本地发票整理工具，目标是解压后双击使用。

## 使用流程

选择或拖入文件、文件夹 → 核对识别结果 → 生成打印 PDF 和 Excel 统计表。

## 计划支持

- PDF、Word（DOCX / DOC）、JPG / JPEG、PNG。
- 自动识别类别、开票日期、发票号码和含税金额。
- 报销人和报销月份可编辑；分类及识别字段可修改。
- 发票去重，识别不清的项目提示人工确认。
- A4 打印，每页最多两张；长发票单页，付款截图最多半页。
- 按类别生成 PDF，并生成全部合并 PDF 和一份 Excel 明细及分类统计表。
- 本机处理，发行包包含必要运行组件。
